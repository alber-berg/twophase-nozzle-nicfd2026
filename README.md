# Two-Phase Supersonic Nozzle Flow — NICFD 2026 (results repository)

Reproducibility repository for the case files, run scripts, and
figure-generation notebooks accompanying:

> Bergamin et al. "A non-equilibrium time-marching model for two-phase
> supersonic nozzle flows." *Proceedings of the 6th International Seminar
> on Non-Ideal Compressible Fluid Dynamics (NICFD 2026)*, ERCOFTAC Series,
> Springer (submitted).

**Status:** under construction. Case configuration files, run scripts, and
figure-reproduction notebooks will be added following the final submission 
of the paper.
